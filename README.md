# Responsive Bookstore Web Layout

A responsive bookstore website designed using HTML and CSS. The layout includes a navigation bar, hero section, book collection, categories, quote section, newsletter subscription, and footer.

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* CSS Media Queries

## Features

* Fully responsive layout
* Mobile-friendly navigation menu
* Responsive hero section
* Book collection cards
* Book categories section
* Newsletter subscription form
* Responsive footer
* Modern typography and custom styling

## Project Purpose

This project was created to practice responsive web design and build a visually appealing website that adapts smoothly to different screen sizes.
